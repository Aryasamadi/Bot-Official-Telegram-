# بنچمارک پایهٔ بار (QA-08 — فاز ۱۳)

**تاریخ اجرا:** ۱۷ اکتبر ۲۰۲۶ · **اسکیما:** v6 · **محیط:** Windows 10 (10.0.19045)، Python 3.13.14، SQLite 3.53.1، دیسک محلی

**روش:** `python tools/benchmark.py --ops 2000 --json bench.json` — دیتابیس موقت SQLite (بدون شبکه، بدون اثر روی نصب واقعی).
هر بلوک n عملیات پشت‌سرهم؛ بلوک `referral_credit_trx` شامل `BEGIN IMMEDIATE` + trigger اتمیک + رسید `credit_log` است.

| بلوک | n | ثانیه | عملیات/ثانیه |
|---|---|---|---|
| users_insert | 2000 | 0.2952 | 6774.9 |
| users_select | 2000 | 0.0308 | 64992.5 |
| articles_insert | 2000 | 0.6338 | 3155.3 |
| referral_credit_trx | 400 | 0.6135 | 652.0 |

**نحوهٔ مقایسه:** همان دستور را با همان `--ops` تکرار کنید و اعداد را با جدول بالا بسنجید.
گلوگاه مورد انتظار مسیر تراکنشی است (`BEGIN IMMEDIATE` + trigger + رسید)؛ افت بیش از ~۲ برابر
در هر بلوک یعنی regression — تا بررسی و رفع، استقرار را جلو نبرید.

> این اعداد «پایهٔ نسبی» برای نصب تک‌فایلی SQLite هستند، نه ظرفیت‌سنجی بار چند-کاربره یا D1.
