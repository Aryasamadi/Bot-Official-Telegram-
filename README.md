# NewsBot v4 — مدیریت خودکار محتوای کانال تلگرام

ربات تک‌پروسه‌ای که منابع خبری (RSS/Atom/JSON Feed/Sitemap/HTML/API) را می‌خواند، با مدل‌های AI
(هر سرویس سازگار با OpenAI/Anthropic/Gemini) بازنویسی و امتیازدهی می‌کند و در کانال تلگرام منتشر می‌کند.

## ویژگی‌ها
- 🌐 کشف چندلایه‌ی منبع: فید → سایت‌مپ → لینک‌های HTML → API سفارشی
- 🤖 AI چندمدلی با fallback، circuit breaker، کش، بودجه‌ی per-article و گزارش زنده
- 📣 انتشار idempotent و crash-safe (ژورنال انتشار + جدول posted)
- 🧾 پلن‌ها، proration منصفانه، کیف پول، کد تخفیف، پرداخت دستی با رسید
- 🤝 سیستم ارجاع (Referral) ضد سوءاستفاده — NEW v4
- 🔐 کانال اجباری فقط برای ادمین‌ها — NEW v4
- ☁️ بک‌اند دیتابیس: SQLite (پیش‌فرض) یا Cloudflare D1 (Source of Truth) — NEW v4
- 🌍 دوزبانه (fa/en) با بازبومی‌سازی خودکار تنظیمات کانال
